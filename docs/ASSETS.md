# Asset provenance

## Fonts (served locally)

Fraunces (regular and italic variable fonts), DM Sans, and Caveat (the handwriting font) are from the Google Fonts repository. Each uses the SIL Open Font License; the original license texts are included alongside the font files under `public/life/fonts/`. No browser request to Google Fonts is made.

Source directories:
- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/caveat

## Code-native visuals

The book icon, botanical illustrations, garden stages, envelope treatment, and constellation are repository-native SVG/CSS. They do not require an image-generation service or a new icon library. The test JPEG is a deterministic canvas drawing generated by `scripts/make-test-photo.mjs`.
